# 测试数据说明

本仓库提交的测试数据仅用于本地开发、自动化测试和界面演示，不应用于生产报送或投资决策。

## 数据清单

| 位置 | 内容 | 来源与用途 |
| --- | --- | --- |
| `data/samples/` | 公司 A、B、C 在 2023–2025 年的 9 份三表样例 | 由 `generate_sample_data.py` 使用固定随机种子生成，用于财报导入、清洗和指标计算测试。 |
| `data/test_*.xlsx` | 模板、矩阵、合并单元格、自动识别与行公司名等测试夹具 | 用于验证模板匹配、填充和复核导出。 |
| `项目指标数据_财务部提供_20260331_测试.xlsx` | 基金项目指标表 | 内容已调整为测试数据，仅用于基金项目解析和导出演示。 |

## 使用约定

- 文件名含“测试”或位于上述目录的文件均视为测试夹具。
- 新增测试数据不得包含真实个人信息、客户信息或未公开业务数据。
- `data/uploads/`、`data/outputs/` 与 `data/cleaned/` 是运行时目录；除非专门评审，不提交其内容，避免上传重复文件或运行产物。
